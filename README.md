# Shadow Hunters

A 2D fantasy action / physics archery game built with **Flutter + Flame** for **Android**.

> **Status:** Phase 0A — Project Foundation. This milestone proves the project starts and that
> Flame renders a game world, with menus and gameplay cleanly separated.

---

## Overview

- **Genre:** 2D Fantasy Action / Physics Archery
- **Platform:** Android (landscape)
- **Engine:** Flutter + Flame
- **Gameplay:** Offline single-player
- **World:** Enchanted Forest
- **Levels:** 15 (V1)

This milestone sets up the project skeleton:

1. App starts successfully (Splash → Main Menu).
2. Flame is wired in correctly.
3. Android is locked to landscape orientation.
4. Splash screen shows **SHADOW HUNTERS**.
5. Main Menu offers **Play**, **Settings**, **Exit**.
6. **Play** opens a Flame `GameWidget` that visibly renders a background + the text
   *"Shadow Hunters Game World"*.
7. Back navigation works (from gameplay and settings back to the menu).
8. Clean, modular folders (`app`, `game`, `screens`, `services`, `widgets`, `assets`).
9. README + `.gitignore` + basic automated tests.

---

## Folder structure

```
lib/
  app/          # App entry point, root MaterialApp + theme
  game/         # Flame game world (gameplay stays separated from Flutter menus)
  screens/      # Flutter UI screens (Splash, Main Menu, Settings, Game)
  services/     # Non-UI logic (save/progress storage)
  widgets/      # Reusable Flutter widgets (menu buttons, etc.)
assets/         # Game assets (images/audio for later phases)
test/           # Automated tests
```

## Getting started

> The platform folders (`android/`, `ios/`, etc.) are generated by the Flutter tooling and are
> intentionally **not** committed. Generate them once on your machine:

```bash
# From the project root:
flutter create --org com.example --project-name shadow_hunters .

# Install dependencies
flutter pub get

# Run on a connected device / emulator
flutter run

# Run the automated tests
flutter test
```

### Building for Android (Codemagic / local)

```bash
flutter build apk --release        # APK
flutter build appbundle --release  # AAB
```

## Game flow (V1)

```
Launch → Splash → Main Menu → Level Select → Gameplay → Win/Lose → Unlock → Boss (L15) → V1 Complete
```

(Level Select, enemies, archery physics, and the boss arrive in later phases.)
